# «Рацион» — генератор недельного рациона

Перенесён из репозитория `savcov89-hub/Diet` (ветка `claude/meal-plan-generator-app-865kpr`). Здесь — как он
считает и откуда данные; как он встроен в Training Log (рамка, «Замеры», назначение клиенту) — в `CLAUDE.md` и `README.md`
в корне.

По опроснику (пол, возраст, рост, вес, активность, силовые тренировки, цель, бюджет, непереносимости, беременность,
лактация, диабет 1/2 типа, ХБП) собирает меню на 7 дней так, чтобы в среднем за неделю выполнялись нормы
МР 2.3.1.0253‑21 и ВОЗ, а стоимость корзины была минимальной для выбранного уровня: эконом / бизнес / премиум.
Все расчёты выполняются в браузере (решатель HiGHS на WebAssembly).

## Команды (из корня репозитория)

```bash
npm run test:ration                        # нормы на 7 профилях (похудение, беременность, ХБП, СД1, веган, лактация, аллергии)
npm run build                              # сайт и «Рацион» в dist/ration/
python3 ration/data/etl/build_products.py  # пересобрать ration/src/data/products.json (скачает USDA, 6 МБ)
```

## Как это работает

1. **Энергия.** Базовый обмен по Миффлину – Сан Жеору × коэффициент активности МР (1,4 / 1,6 / 1,9 / 2,2).
   Беременность +250/+350 ккал по триместрам, лактация +500/+450 (МР 2021). Цель «снизить вес»: дефицит 500–700 ккал
   (КР «Ожирение» 2024), не ниже 1200/1500 ккал (AHA/ACC/TOS 2013), при лактации дефицит ≤500 и не ниже 1800 ккал
   (Lovelady 2000), при беременности дефицита нет, при ХБП — не ниже 30 ккал/кг.
2. **Нормы на день** (`src/core/norms.ts`). Витамины и минералы по МР 2.3.1.0253‑21 с учётом пола, возраста, триместра и
   периода лактации; верхние пределы EFSA/IOM; жиры ≤30 %, НЖК ≤10 %, транс ≤1 %, соль <5 г, клетчатка ≥25 г,
   овощи и фрукты ≥400 г (ВОЗ). Белок: без силовых 0,8–1,5 г/кг (65+ — 1,0–1,5), при похудении 1,2–1,8
   (Leidy 2015, Wycherley 2012), при наборе 1,4–2,0; при силовых 1,6–2,0 г/кг, при похудении 1,6–2,2
   (Morton 2018, ISSN 2017); при ХБП по стадии, С3б–С5 0,6–0,8 и 1,0–1,2 на диализе (КР ХБП 2024, KDIGO 2024,
   KDOQI 2020) — ХБП сильнее силовых. Калий и фосфор по стадии ХБП; при диабете клетчатка
   ≥14 г/1000 ккал, добавленные сахара ≤5 %, исключение сахара/мёда/варенья, ХЕ по приёмам (1 ХЕ = 10 г).
3. **Корзина на неделю** (`src/core/solver.ts`). Смешанно-целочисленная задача (HiGHS): минимизировать стоимость
   (в бизнес/премиум — с поправкой на «качество» продукта) при выполнении норм за 7 дней, лимитах на продукт и группу,
   долях разнообразия (ни один овощ >35 % овощей и т.п.) и минимумах (рыба ≥300 г, бобовые ≥150 г). Продукт либо не
   покупается, либо берётся не меньше реалистичного объёма (`min_week_g`: рыба 350–500 г, мясо 400 г, крупа 150 г).
   В списке покупок граммы пересчитываются в упаковки и тушки (`pack_g`, `pack_label`) с подсказкой, как покупать.
   Минимумы по витаминам — мягкие со штрафом: задача всегда решается, а недобор честно показывается (например, витамин D).
4. **Меню** (`src/core/planner.ts`). Порции раскладываются по дням и приёмам, выравнивая калории (и углеводы при
   диабете), чтобы в обед и ужин были овощи и не было двух гарниров.
5. **Доказательная база** (`src/core/evidence.ts`). Каждое правило ссылается на документ; список со ссылками —
   раздел «Источники» в приложении.

## Вкусняшки

По умолчанию в рационе заложен бюджет на десерт ≈120 ккал/сут (можно выключить или поднять до ≈220) в пределах нормы ВОЗ
по добавленным сахарам (10 %, при похудении и диабете 5 %). Можно отметить любимое: зефир, пастила, мармелад, халва,
овсяное печенье, пряники, пломбир, шоколад, глазированный сырок, мёд, варенье. При диабете остаётся только горький шоколад.
Обоснование: гибкий контроль питания без полных запретов лучше удерживает вес (Westenhoefer 1999, Teixeira 2010).

## Данные

- `data/etl/catalog.py` — 150 продуктов: русские названия, категория, теги (lactose, gluten, egg, fish, nuts, soy, pork,
  red_meat, pregnancy_avoid, added_sugar, high_gi, regional, treat …), цены по трём уровням (руб/кг), сезонность, роли
  в приёмах пищи, недельные лимиты, упаковки и подсказки покупки, идентификатор USDA. **Цены правятся здесь.**
- `data/etl/build_products.py` — собирает `src/data/products.json` из каталога и USDA FoodData Central SR Legacy
  (public domain, 35 нутриентов на 100 г). Йод и облепиха добавлены вручную по Скурихину (2002) и помечены.
- Цены примерные розничные (октябрь 2026), в приложении подписаны «в вашем городе и магазине могут отличаться» —
  без привязки к городу. Позиции с оценкой помечены флагом `est` и знаком «≈» в списке покупок.

## Ограничения

- Нормы для взрослых 18+. Беременность с диабетом, диализ и тяжёлые состояния — только как ориентир для обсуждения
  с врачом; приложение показывает соответствующие предупреждения.
- В USDA SR Legacy мало данных по витамину D и йоду; недобор витамина D может быть завышен, йод заведён вручную.
- Расчёт 2–4 секунды в браузере из‑за целочисленных ограничений.
- При тяжёлой ХБП с ограничением калия и фосфора возможен честный недобор цинка и кальция — виден в разделе «Нормы».
